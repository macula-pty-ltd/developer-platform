# Developer environment design
Inherit the MACULA Explorer dark-green palette, mint actions and restrained sans typography. Application shell with persistent compact navigation; landing uses clear first action and code/workflow preview rather than oversized promotional headings. Playground uses editor plus compiler/deployment console, persistent Sandbox/Mainnet mode, status and next action. Library uses informative rows grouped by difficulty. Docs use readable 70ch prose and copyable code. Shared semantic tokens in src/styles.css. Every actionable control has a working handler, progress/error/empty feedback and keyboard focus. Legal text 12px. Mobile stacks panels with no horizontal page overflow.
